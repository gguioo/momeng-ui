> 宣纸为底，松烟墨为线，朱砂为印。

墨萌的视觉来自两个看似矛盾的世界：

| | **墨 · 古典人文** | **萌 · 卡哇伊** |
|---|---|---|
| 材质 | 宣纸、绢、墨、印泥、木轴 | 贴纸、和纸胶带、手帐 |
| 线条 | 毛笔笔触：起笔重、收笔轻，有飞白 | 圆润、不规则、带一点抖 |
| 色彩 | 中国传统色，沉静而有温度 | 桃夭腮红，一点点就够 |
| 节奏 | 留白、舒缓、竖排、汉字数字 | Q 弹、回弹、表情、歪头 |
| 情绪 | 雅致、可信 | 亲切、治愈 |

我们不做「中国风皮肤」，也不做「可爱贴纸」。墨萌要做的是：**用书画的秩序托住可爱，用可爱的温度化开古板。**

## 四个关键词

### 留白 · Liubai

中国画「计白当黑」。墨萌默认使用宽松的间距与较少的装饰，让内容先呼吸。
**一个视图里，装饰性元素（印章、胶带、墨团）不超过两处。**

### 笔意 · Brushstroke

所有描边都像手画的：不规则圆角 `--mo-radius-hand`、2px 墨线、错位实影 `--mo-shadow-stamp`。
分割线、Tab 下划线、菜单高亮都使用同一枚「毛笔横画」笔触资源，保证笔意统一。

### 印信 · Seal

朱砂是整个系统里**最贵的颜色**。它只用于：主要行动点、当前状态（当前页、进行中的步骤）、印章。
就像一幅画上只钤一两方印，朱砂用多了就廉价了。

### 萌趣 · Kawaii

可爱是一种**反馈**，不是装饰。墨团只出现在空状态、加载、确认、通知、头像兜底 —— 这些都是用户需要被安慰或陪伴的时刻。
动效的 Q 弹只发生在「用户刚刚做了一件事」之后。
