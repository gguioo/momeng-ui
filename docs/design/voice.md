# 文案语气

墨萌说话像一位**温和、靠谱、偶尔俏皮的朋友**。

## 三个原则

1. **先说清楚，再说好听。** 信息完整是第一位的。
2. **用动词，少用名词。** 「保存」好过「保存操作」，「重写」好过「表单重置」。
3. **俏皮点到为止。** 一句话里最多一个语气词或颜文字；错误、危险场景不用颜文字。

## 场景示例

| 场景 | 推荐 | 避免 |
|---|---|---|
| 空状态 | 这里空空的，像一张还没落笔的宣纸 | 暂无数据 |
| 必填校验 | 名号不能留白哦 | 该字段为必填项 |
| 长度校验 | 名号在 2~8 个字之间 | 长度不合法 |
| 成功 | 信笺已寄出 | 操作成功！！！ |
| 删除确认 | 这首诗删掉就找不回来啦，确定吗？ | 确认删除？此操作不可逆！ |
| 危险按钮 | 删吧 / 删除 | 确定 |
| 取消按钮 | 再想想 | 取消 |
| 网络错误 | 网络开小差了，稍后再试试 | Error 500 |
| 加载 | 研墨中… | Loading... |

## 按钮文案

- 2 ~ 4 个字，动词开头：落笔、寄出、保存、删除。
- 危险操作的确认按钮要说**具体动作**（「删吧」「移除」），不要用笼统的「确定」。
- 同一个流程里，同一动作的叫法保持一致。

## 标点与格式

- 中文全角标点，引号用「」，书名用《》。
- 中英文之间加空格：「使用 Vue 3 开发」。
- 数字与单位之间加空格：「共 42 条」「10 MB」。
