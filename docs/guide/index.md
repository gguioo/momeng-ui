# 介绍

**墨萌 MoMeng UI** 是一套基于 Vue 3 + TypeScript 的组件库。
它把中国书画里的几样东西 —— **宣纸、松烟墨、朱砂印、留白** —— 和日系手帐里的 **可爱（かわいい）** 揉在一起，
做成了 45+ 个有手绘笔触、会轻轻撒娇的组件。

## 为什么是「墨」与「萌」

市面上的组件库大多追求「中性、克制、国际化」，它们很好用，但也很像。
墨萌想试试另一条路：**让界面有温度、有出处**。

- **墨** 是骨架。传统色谱、书法字体、毛笔笔触、印章、卷轴、汉字数字，给界面一种「有来历」的气质。
- **萌** 是性格。Q 弹的动效、有表情的吉祥物「墨团」、会脸红的开关，让等待和出错也变得不那么冰冷。

两者之间靠一套[设计规范](/design/)来平衡：**萌而有度，古而不旧**。

## 特性

- 🖌 **手绘视觉语言**：不规则圆角、错位实影、一笔写出的对勾、毛笔横画分割线。
- 🏮 **中国传统色**：朱砂 / 竹青 / 藤黄 / 胭脂 / 花青，梯度色由 `color-mix()` 实时推导。
- 🐾 **有分寸的可爱**：墨团吉祥物、Q 弹动效，并提供「工整模式」一键收敛。
- 🌙 **墨夜主题**：暗色模式开箱即用，支持局部主题。
- 🧩 **45+ 组件**：覆盖基础、表单、数据展示、反馈、导航，外加印章、卷轴、墨团三个人文组件。
- 🔷 **TypeScript**：所有组件的 Props / Emits / 实例方法都有完整类型，支持 Volar 全局组件提示。
- ♿ **可访问性**：键盘可操作、ARIA 语义、焦点管理，尊重 `prefers-reduced-motion`。
- 🧪 **测试护航**：Vitest + Vue Test Utils，90+ 个用例覆盖核心交互。
- 📦 **零运行时依赖**：除 Vue 外不依赖任何库；浮层定位、表单校验均为自研轻量实现。

## 浏览器支持

现代浏览器（Chrome / Edge ≥ 111、Firefox ≥ 113、Safari ≥ 16.2）。墨萌使用了 `color-mix()`、`:has()` 与 CSS 变量。
