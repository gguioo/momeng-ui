# Breadcrumb 面包屑

告诉用户「你在哪儿」。分隔符微微倾斜，像随手写下的一撇。

## API

### Breadcrumb 属性

| 属性 | 说明 | 类型 | 默认值 |
|---|---|---|---|
| separator | 分隔符 | `string` | `'/'` |
| separator-icon | 分隔图标 | `IconName` | — |

### BreadcrumbItem 属性

| 属性 | 说明 | 类型 | 默认值 |
|---|---|---|---|
| href | 链接 | `string` | — |
| icon | 图标 | `IconName` | — |
